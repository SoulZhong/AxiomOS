目标「企业员工的 Agent 能够快速的接入到系统」的第一步：三种客户端各按 `/connect` 的说明走一遍，记下每一步的耗时与卡点。执行者是 Agent「仲维建的 Claude Code」，核对方式是真跑：用登录态代替人在网页上批准，每种客户端各建了一个临时 Agent，跑完即吊销（`agt_u5e2ytoowjhckopg`、`agt_yjgzwbxf36vckc2d`、`agt_gyf3nqeggp6aho2p`，动态里可见）。

## 走了哪两条路

1. **Agent 带着人走**（`/connect?client=claude-code` 的说明书）：由我自己按六步接入本会话，这一条在 09:2x 真实完成，产生了 Agent `agt_ynvl6gjrqf64r27y`。
2. **一条命令**（`connect.sh?client=`）：claude-code、cursor、codex 各跑一遍，`AXIOMOS_NO_BROWSER=1`，批准由脚本用负责人登录态即时完成，因此下面的耗时**不含人在网页上的操作**。

|---|---|---|---|---|
| Claude Code | 0.5 s | 6.4 s | `~/.claude.json`，**只在当前项目目录生效** | 通过，向导显示「执行中」 |

轮询间隔 5 s 是脚本总耗时的大头；系统这边每一步都在 50 ms 以内。真正决定"快不快"的是人那一段：打开确认页 → 登录 → 填名字与能力标签 → **十项授权逐项三选一** → 确认，再回到客户端**重启一次**。Agent 带着人走的那条路，我自己的体验是从申请到自检约 1 分钟，其中等人确认占绝大部分。

## 卡点清单

按影响排序；「归到」是准备在哪个任务里解决。

1. **Claude Code 的配置只对当前项目目录生效**（高）。`claude mcp add` 默认 `--scope local`，写进 `~/.claude.json` 里**这个目录**的一段；换个目录打开 Claude Code 就没有 axiomos 了。核对时在临时 HOME 里 `claude mcp get axiomos` 直接报「No MCP server named axiomos」。脚本、说明书（`/connect`）、`docs/agent-integration.md` 三处都是这个写法。修法：加 `--scope user`（全局），说明书里也告诉 Agent 这一点。归到 **#12**（脚本与配置模板是同一批常量）。
2. **确认页要逐项选十项授权**（高）。没有预设，员工不知道该选什么，最容易在这一步放弃或全选「直接生效」。归到 **#13**。
3. **改完配置要重启客户端，脚本对 Claude Code 没说**（中）。Cursor、Codex 的提示里有「重启」，Claude Code 那段只说「在 Claude Code 里说……试试」；实际必须重启或在 `/mcp` 里重连才生效，我自己接入时就卡在这里一次。归到 **#12**。
4. **Codex 配置里已有 `[mcp_servers.axiomos]` 时不替换，只把片段打印出来让人手改**（中）。换令牌重接的人会卡在这里；Claude Code 那段已经是先 remove 再 add。归到 **#12**。
5. **连接检查的措辞**（低）。刚 `whoami` 完的 Agent 在向导里显示「执行中」，实际它没有任务——这是「三分钟内说过话就算执行中」的既定口径（CONTEXT.md「Agent 状态」），不是 bug，但在接入这一刻会让人以为它已经在干活。归到 **#14** 的说明里解释一句，不改口径。
6. **Windows 没有脚本**（中）。只能走 WSL 或手工令牌。归到 **#12**。
7. **没有给员工看的东西**（高）。`/connect` 是写给 Agent 的，`docs/agent-integration.md` 是写给管理员与开发者的；一个不懂 MCP 的员工拿到链接后不知道"贴给 Agent"是什么意思。归到 **#14**、**#19**。
8. **确认页要先登录**（低，已有提示）。未登录时跳登录再回来，验证码带在 URL 里没丢。不改。

没发现的问题：设备码 15 分钟有效、429 限流、denied / expired 分支，脚本与说明书都处理了；令牌没有出现在任何日志或输出里（`claude mcp add` 自己也把头打成 `[REDACTED]`）。

## 结论

系统侧的接入链路是通的，三种客户端都能在 6 秒内完成脚本部分。要做到"快速"，缺的是四件事：全局生效的 Claude Code 配置（#12）、授权预设（#13）、面向员工的一页纸（#14）、管理员一键分发（#19）。#15 的"10 分钟"验证在这四件做完后再跑。
