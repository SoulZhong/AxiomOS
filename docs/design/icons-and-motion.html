Axiom 图标与动效

《机器人总动员》里，每台机器人都有一条指令，人类船长握着最终的舵。这与 AI 原生组织的结构完全同构：Agent 各有能力标签与任务，人负责目标、验收与批准。下面把这套设定翻译成一组图标和一组动效，每一个都对应系统里一个真实概念或真实状态。

规则先说在前面：类比只用于设计推导，界面上仍然只出现《CONTEXT.md》里的词。用户看到的是「目标」「待确认操作」「验收」，不是「植物」「舵轮」「扫描」。装饰不占信息空间，动效只在状态真正变化时发生。

一、设定与组织的类比

有意不做类比的：躺在悬浮椅上的乘客（这是反面教材，系统的目标是让人保持在决策位上）、BnL 公司、机器人修理舱。

二、签名图标（20 枚）

整套图标沿用 Linear 式规格：24 网格、1.5px 描边、圆角端点、单色随文字色。只有这 20 枚是"签名"图标，承载类比；其余（设置、搜索、筛选、关闭……）直接用 Lucide，不另画。每枚都在 16px 与 32px 两个尺寸下检查过可辨识度。

目标
靴子里的植物
目标是"证据"而不是口号。未完成时只有芽，完成后长出叶子。
任务
压实的方块
一个可交付的工作单位。侧栏、列表、命令面板统一用它。
进行中
正在压缩
四周的短线表示"正在被压实"；只用于状态标记，不进导航。
待领取任务
方块堆
等着被领走的工作。领取动效从这里"取走一块"。
Agent
视窗与双点
双点是状态语言：在线常亮、执行中交替、离线变暗。不画脸、不做表情。
成员
现有头像
保持通用人形，与 Agent 的视窗形成"人 / 机"对照。
验收
EVE 的扫描
中线是扫描线；进入待验收时扫一次，通过后中线消失。
待确认操作
船长的舵轮
Agent 提议，人来转舵。批准时转四分之一圈，拒绝时回正。
执行记录
进度环中的播放
环表示一段执行的进度，缺口处是尚未完成的部分。
用量 / 成本
太阳能电池
电量就是预算；三格随预算使用比例变化。
Bug
M-O 的刷子与异物
异物是那个点，刷子是处理它的动作。
发现于
追踪的痕迹
从 Bug 追溯到它出现的需求或发布。
阻塞
链
通用链环，前置被取消时链自动断开（动效）。
逾期
时钟加告警灯
右上的点是 LED，沿用"双闪后休息 4 秒"的节律。
已取消
气闸
送出去，不是删除；记录仍在。
通知
桅顶信标
有新通知时信标闪两下，不摇铃铛。
参与角色 / 交接
双星环绕
与登录页舰徽同源，人与 Agent 各是一颗，围着同一个任务转。
甘特图
航线
实线是计划，虚线是前后依赖。
动态
录像带
被记录下来的事；与舰桥日志的等宽时间戳搭配。
组织
客轮剪影
只作默认组织头像与后台组织列表，不进导航。

三、动效样稿

动效只在状态真正变化时发生，时长不超过 240ms（唯一例外是慢速环境动效）。每条都写明触发条件；点「播放」看效果。

任务完成 · 压实420ms

触发：任务进入成功终态。方块先收缩 15% 再回弹，LED 转为绿色。像 WALL·E 压完一块。

目标完成 · 发芽480ms

触发：目标进度到 100%，且全部子任务验收通过。茎先长、叶后展，一次绿色微光。上级目标的仪表随后扫动。

Agent 上线 · 充电520ms

触发：收到 Agent 第一次心跳。外环顺时针充满，双点随后点亮。之后心跳是 3s 呼吸；离线时 400ms 变灰。

Agent 执行中 · 双点交替环境 · 1.4s
执行中 · 已 12 分钟

触发：该 Agent 有打开的执行记录。两点交替明暗，幅度 70%，永不同步闪烁。

领取任务 · 取走一块260ms
整理 Q3 供应商合同清单我

触发：从待领取任务点「领取」。方块堆退场，任务行从左滑入"我的任务"。

进入待验收 · 扫描320ms
登录页视觉与交互改版待验收

触发：任务进入等待验收的状态。一道扫描光从左到右扫过该行一次，通知验收人。

批准待确认操作 · 转舵240ms
批准

触发：负责人批准 Agent 的提议。舵轮转四分之一圈并亮灯；拒绝时回正、不亮灯。这是全系统最重要的一次动效：人接管了舵。

新通知 · 信标900ms

触发：有新的待办通知。信标闪两下后常亮，不摇晃、不弹跳。

逾期 · 双闪后休息环境 · 5s
面谈两位候选人并出评估 · 逾期 2 天

触发：计划结束早于今天且未结束。快速两闪，然后休息 4 秒，避免持续闪烁。

交接 · 双星环绕环境 · 12s
小李 → 小李的 Claude Code

触发：任务在人与 Agent 之间交接时的短暂提示。慢速环绕一圈 12 秒，只出现在交接确认框里。

成本变化 · 数字滚动160ms/位
¥25.078

触发：读数刷新且数值变化。只滚变化的位，从右向左。已经在状态栏与看板里上线。

阻塞解除 · 断链200ms
前置「官网 v2.0 上线」已取消

触发：前置任务被取消，依赖自动释放（ADR 0006）。链环分开 4px 再淡出，被阻塞的任务 LED 亮起。

四、Agent 的状态语言

EVE 的眼睛是整部电影最好的界面：不说话，只靠形状与亮度传达状态。系统里 Agent 的双点沿用这个思路，但只用亮度与节律，不做表情：

状态双点环含义
在线常亮3s 呼吸有心跳，可以领任务
执行中交替明暗常亮有打开的执行记录
等待输入常亮，偏暖静止Agent 发起了「请求输入」，需要人回答
离线暗 25%灰、静止心跳超时；执行记录会被系统收尾
被注销不显示不显示只在历史记录里出现

五、原则与禁区

会做的
  • 图标承载概念，动效承载状态变化；两者都能被写进《CONTEXT.md》的一句话解释。
  • 界面文字只用系统词汇；类比留在设计文档和代码注释里。
  • 所有动效 ≤ 240ms，环境动效（呼吸、环绕）慢而低幅，永不同步闪烁。
  • 尊重系统「减少动态效果」：一律直接落到终态。
  • 深色与浅色主题同一套图标，单色随文字色。
不做的
  • 不做吉祥物、不画脸、不做表情包式的 Agent。
  • 不在内容区放任何装饰画面；母舰只属于登录页。
  • 不做扫描线、粒子雨、打字机文案、霓虹描边、彩色渐变图标。
  • 导航切换只留 100ms、只动透明度的极轻进场（已确认的折中）；其余高频操作零动画，键盘操作永远即时。
  • 不用声音。

六、落地顺序

  1. 图标替换：侧栏与列表换上 20 枚签名图标，其余沿用 Lucide；同时更新命令面板与状态徽标（半天）。
  2. 状态动效：任务完成压实、目标发芽、进入待验收扫描、批准转舵、Agent 上线充电与执行中交替、逾期双闪、新通知信标（一天）。
  3. Agent 状态语言：Agent 列表与详情按第四节的表实现双点与环（半天）。
  4. 交接与断链：交接确认框的双星环绕、依赖自动释放的断链（半天）。

每一步都在深浅两个主题下和「减少动态效果」下验证；不经你确认不改任何界面词汇。
