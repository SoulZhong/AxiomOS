# ADR 0022：路线图用粗刻度时间线，日期粒度决定条怎么画

日期：2026-09-07 · 状态：已采纳 · 取代 ADR 0021 的第 3、4 条 · 关联：0012（视图）、0016（里程碑）、0014（可定制边界）

## 背景

ADR 0021 把路线图定成"现在 / 下一步 / 以后"三列且不画时间条。做出来之后不理想，原因在实现里看得很清楚：目标身上本来就有计划起止和里程碑日期（演示组织里「官网 v2.0 上线 10月5日」这样的真实日期），三列把它们压没了；父子目标被拆进不同列，目标树这个骨架断了；四列各一两张卡，空间浪费。

`docs/design/sources/roadmap-survey.md`（2026-09-07，逐页核对了约二十个产品）给出的关键事实：**没有一家主流工具靠"取消时间轴"来避免把路线图变成排期表，他们靠的是降低刻度**。Jira Product Discovery 的原话是"它意在呈现一个非常高层的视图，因此不到周的精度"；Aha! 用雾边表达粗粒度；Jira Plans 用斜纹表示"这条是从子项推出来的"；Linear 规定一旦手工拖动就把粒度落实到日。

## 决策

1. **路线图只有时间线一种排布**。用户明确否掉了卡片式的分列排布，原来那套卡片全部删掉，不留作第二排布。目标页仍是路线图 · 树 · 甘特图三个页签，默认仍是路线图。
2. **时间线排布**
   - 横轴只开 **周 / 月 / 季度（默认）/ 年** 四档，复用甘特图已有的刻度实现，**最小到周，不开天与小时**：那是甘特图的事。保留今天线。
   - 一行一个目标，子目标缩进可折叠；折叠后父行画跨整棵子树的汇总条。
   - 泳道默认按团队，可切按负责人或不分组。
   - 左侧固定信息列约 320px：目标标题（前面一枚信心度圆点）、成果指标（单行截断）、负责人、进度条与百分比。"一眼读出进度与信心"靠这一列，不靠条。
   - **条有四种画法，把"这个日期有多硬"画出来**：粒度到周是硬边实条（两端吸附到周一与周日）；粒度是月 / 季度 / 半年 / 年时两端吸附到刻度并做渐隐雾边；自己没填、由子目标推出来的画斜纹并在标题旁加箭头，推算值**不落库**；完全没有日期的见下。
   - 里程碑是条上的菱形，逾期标红、已达到打勾。**这是路线图上唯一出现具体某一天的地方**：里程碑本来就是"到这一天应该达到什么"（ADR 0016），它的日期是承诺，条的起止不是。
   - **没有日期的目标不藏起来**：沉到本泳道底部的「还没排期」分组，右侧从今天线起画一根极淡的幽灵条，按住往右拖即写入计划起止；工具条上有「只看已排期」开关。
   - **拖动就是表态**：拖条或拖两端会把日期粒度落实成"到周"；想回到粗粒度去目标详情改。
   - **路线图上不画任何任务**。往下钻的路径是：展开子目标 → 进目标详情 → 跳到任务甘特图并预置筛选。
3. **时间桶降为分组与兜底，不再有自己的排布**：时间线的泳道可以切换成"按时间桶分组"，供还没排期的阶段用；有日期的目标，其时间桶只作显示，日期永远优先。
4. **目标新增两个字段**：
   - **时间粒度**（`date_precision`，取值 `week | month | quarter | half | year`，可空等价于 `week`）。语义是"日期填到多细为止"，**最细到周**：路线图不承诺某一天。与信心度正交：可以季度粒度加高信心度，也可以到周加低信心度。吸附、雾边、对外降精度、分列派生都靠它。
   - **排序权重**（`rank`，可空）：泳道内的手动次序，用于表达"这个更要紧"。
5. **对外只读分享按粒度降精度**：粒度是季度就只显示"2026 年第四季度"，不发具体区间；仍不含成本。
6. **汇总只在读时算**：父目标自己填了计划起止就用自己的，没填才从子目标与任务推算，推算值不写回数据库。

## 被否决的

- **卡片式的三列排布**（本轮已实现又删掉）：三列法的单位是还没定型的问题，靠"越远越粗"省信息；我们的目标一立项就有负责人、团队、里程碑、进度、预算，塞不进卡片。更要命的是把时间桶做成与日期无关的独立枚举，会让同一个目标有两套互相矛盾的时间表达。用户看过实现后直接否掉了卡片。
- **价值/成本四象限当主视图**：那是取舍用的视图，缺一个轴的目标直接消失，也没有负责人、进度、里程碑的位置。以后可以做成新建目标时的排序辅助。
- **山丘图**：点靠人手拖，而我们有真实的汇总进度，用手拖的点盖住真数据是倒退。但它的**历史快照**思路值得单独立项：动态是只增不改的，按周回放一个目标的条与里程碑成本很低。

## 页面规格（照这个实现）

**整页结构**：目标页三个页签不变，路线图仍是第一个与默认。路线图页内自上而下是工具条、时间线、底部的「还没排期」。

**工具条**（一行，左起）：范围选择（沿用全局的）· 刻度分段（周 / 月 / 季度 / 年，默认季度）· 「回到今天」· 分组（团队 / 负责人 / 时间桶 / 不分组，默认团队）· 筛选（负责人、信心度、状态）· 「只看已排期」开关 · 「新建目标」。刻度与分组记住上次选择。

**时间线**：左侧固定信息列 320px 不随横轴滚动，右侧是时间区；两者共用行高 44px，泳道头 32px。
- **信息列一行四段**：① 折叠箭头（有子目标时）+ 信心度圆点 + 目标标题（截断，悬停出全名）；② 成果指标，单行截断、淡一级，没填时不占行；③ 负责人头像与名字；④ 细进度条 + 百分比。行高固定，②没填时其余三段垂直居中。
- **时间区**：表头两行，上行是大刻度（季度或年），下行是小刻度（月或周）；今天线是一条 1px 的强调色竖线，带顶部标签。
- **条**：高 18px、圆角 4px，按汇总进度填充（进行中 / 已达成 / 已放弃三种语气沿用甘特图）。四种画法：到周＝硬边、两端吸到周一与周日；月及以上＝两端吸到刻度边界并做一格宽渐隐；由子目标推算＝斜纹 + 标题旁一枚箭头，只推出一头的那一头渐隐；没有日期＝幽灵条（见下）。条上悬停出气泡：目标名、区间（按粒度措辞，如「2026 年第四季度」）、负责人、进度、里程碑条数。
- **里程碑**：条上的菱形，沿用甘特图的渲染与配色，逾期实心红、已达到打勾；悬停出名称与日期。密集时同一周内的合并成一枚并在气泡里列全。
- **子目标**：默认折叠，父行画跨子树的汇总条；展开后子目标缩进 16px 一级，最多三级（更深的在目标详情里看）。折叠状态记在本地。

**交互**
- 拖条移动、拖两端改长短，吸附到当前刻度的边界（季度刻度下按月吸，月刻度下按周吸）；松手写 `planned_start` / `planned_end` 并把粒度落实成"到周"。没有编辑权的人拖不动，悬停给一句原因。
- 双击条空白处新建里程碑（沿用目标详情里的那套）。
- 单击行选中，回车进目标详情；行尾一个按钮跳到任务甘特图并预置该目标的筛选。
- 泳道内可上下拖动排序，写 `rank`。

**还没排期**：时间线底部一个常驻分组（不是弹层），左侧照常显示信息列，右侧从今天线起画一根极淡的虚线幽灵条，上面一句「按住往右拖就算排期了」。拖出来即写入计划起止与"到周"。工具条上的「只看已排期」把这一组收起。

**空态**：一个目标都没有时，中间一句「路线图上还没有目标。先建一个，把它拖到时间线上。」加「新建目标」。全部目标都没排期时，时间线区给一句「还没有目标排上时间线」。

**窄屏（<1024px）**：信息列压到 200px 且只留标题与信心度圆点，其余进悬停气泡；刻度强制为季度。

## 以后可以考虑

调研里第二种对得上的形式是**成果表**：一行一个目标，列是时间、名称、成果指标、进度、负责人。它是表不是卡片，扁平、能直接读、适合贴进文档或对外发。现在不做，等真的需要"把路线图发出去"时再说。

## 后果

- 迁移新增两列，旧目标全空、行为不变。
- ADR 0021 的三个字段、三档写死、泳道口径、分享规则全部保留；被取代的只有"永远不画时间条"和"默认分列"两条。
- 甘特图页签保持不变，仍是任务级的精确排期。

## 补记（2026-09-08）：目标页只留路线图与树

路线图做出来之后，用户指出目标页的「甘特图」页签与它画的是同一批行——都是目标、都嵌套子目标可折叠、都在条上画里程碑、都能拖两端改计划起止；差别只剩粒度雾边、泳道、类型与信心度、以及没日期时的画法。这是引入路线图造成的重复。

- **删掉目标页的「甘特图」页签**，目标页只留「路线图 · 树」，默认仍是路线图。`?view=gantt` 重定向到路线图。
- 把目标甘特图独有的两件事并进路线图：**行空白处双击新建里程碑**（日期取双击处）与**截止日的短刻度**。拖菱形改日期路线图已有。
- **任务页的「甘特图」保留原名**：它画的是任务，有依赖、执行记录、成本、按天的刻度，是另一个对象、另一个粒度。两个名字虽来自两套分类法（一个按用途、一个按图表类型），但指向的东西不同，不再是同一张图的两个叫法。用语原则是"用人们已经在用的词"，甘特图在中文项目管理语境里就是那个词；路线图刻意不做依赖、不到天，叫甘特图反而不准确。
