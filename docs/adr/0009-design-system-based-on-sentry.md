# 界面设计规范以 Sentry 的设计语言为蓝本

系统要给整个组织用，界面必须密集、可扫读、动作明确，同时要有辨识度。我们决定不从零发明视觉语言，而是以 Sentry 的设计体系为蓝本合成一份自己的规范（`web/DESIGN.md`）：产品界面沿用 Sentry 产品端的 token（Rubik 字体、11–40px 字阶、2–32px 间距、3–16px 圆角、蓝紫强调色、中性灰面板、无粗体、面板无阴影），品牌面（侧边栏、登录、后台顶栏、空状态）沿用 sentry.io 营销站的午夜紫罗兰画布与"一屏一处"的青柠高亮。来源存于 `docs/design/sources/`。

## Considered Options

- **自研视觉语言**：自由度最高，但没有设计师的情况下容易失衡，且每次改版都要重新论证。
- **直接套 Sentry 营销站的 DESIGN.md**：88px 标题、2.0 行高、贴纸插画是营销页节奏，不适合每天盯着看的工作台。
- **产品 token + 品牌面分层（选定）**：工作页面用产品端的密度与克制，外壳与入口页用品牌画布提供个性；两个世界不混用，这也是 Sentry 自己的做法。

## Consequences

- 所有界面变更必须先对照 `web/DESIGN.md`；新 token 先加进规范再用。
- 强调色只有一个（`#653de9`），青柠每屏最多一处，没有粗体、没有渐变、没有卡片阴影。
- 组件名与 token 名沿用规范里的 `{components.*}` / `{colors.*}`，方便未来把规范交给任何 Agent 直接生成一致的界面。
