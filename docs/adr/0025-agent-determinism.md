# ADR 0025：让人经由 Agent 与系统交互时是确定的

日期：2026-09-08 · 状态：已采纳 · 关联：0003（Agent 权限）、0018（设备码）、0024（接入链接）、0002（动态是骨架）

## 背景

人对 Agent 说一句"把那个任务标记完成"，Agent 要猜是哪个任务、走哪一步；同一句话这次调三个工具、下次调五个，副作用不一样；系统又在该给编号的地方接受自由文本。三重不确定叠加，结果是用户觉得"和系统交互不稳定"。

已有的基础：24 个语义清晰的 MCP 工具、任务可用 `#123` 指代、六类拒绝理由与网页同句、需要人确认的操作会挂起。缺的是**把人的意图变成确定操作**的那一层。

## 决策

1. **提供 MCP 提示（prompts），客户端会显示成斜杠命令**。这是把"语言描述"变成"确定操作"的载体：人选命令、填参数，Agent 收到的是结构化输入，不经过语义猜测。首批八条：领任务、开始执行、提交交付、提问、看我的任务、看某个任务、写进展、汇报用量。提示由服务器定义，随系统升级，客户端零配置。
2. **写操作可以先看后做**：所有写类工具接受 `dry_run`，返回"我将要做什么"的一句中文，不产生任何改动、不写动态。Agent 先念给人听，人点头再真做。与"需要人确认"的授权是两道独立的闸：前者防误解，后者防越权。

   范围是**Agent 代人做事的那一路**：任务、目标（含批量改时间桶与批量重排）、里程碑、迭代。组织配置类的接口（角色与权限、能力标签、目标类型、计价、组织信息与策略、通知设置、代码平台、外部目录、成员与团队、工作台布局、待确认操作的裁决、设备码的同意与拒绝）不在范围里：那是人在网页上按按钮，网页自己就有确认框。**不在范围不等于可以偷偷写**：这类接口收到 `dry_run` 一律拒绝并说明「这个操作还不支持「只看不做」，所以什么都没做。」兜底钉在 `app.insertEvents` 上（硬规则"任何写操作都要产生动态"让它成为所有写路径的必经之处），不记动态的那几条路径在入口处各自挡一下。唯一不收 `dry_run` 的写类工具是 `heartbeat`：Agent 每 60 秒自动打的心跳，预演它没有意义。
3. **写操作接受幂等键** `idempotency_key`：同一个键在 24 小时内重复提交只生效一次，第二次返回第一次的结果并注明"这次没有重复创建"。说两遍"建个任务"不该建出两个，这是系统的责任，不靠 Agent 自律。

   做法是**先占位再干活**，不是"做完再记一笔"：先把键以 `pending` 状态插进表里，插进去了才开始真做。占位发生在副作用之前，所以同一个键的两个请求同时进来时，唯一索引在门口就挡住了后来的那个——"做完再记"挡的是记录，副作用早已各自提交，那正好是幂等键要防的事。占位带一条 60 秒的租约：租约内的同键调用回一句「同一个幂等键上一次的调用还在进行中，等它做完再说。」；超过租约说明上一次的进程死了，后来者接手继续做。做成了把占位改成 `done` 并存下结果，做砸了把占位删掉——失败本来就该允许重试。只看不做一个位都不占。
4. **`next_actions` 工具**：返回当前上下文下**带编号的可执行动作清单**（每条含编号、一句话、对应的工具与参数）。Agent 把清单念给人，人说"第 2 个"。把自由聊天变成选菜单，是消除歧义最省事的办法。
5. **精确指代扩展到所有对象**：任务 `#123`、目标 `目标:标题` 或 `G-编号`、成员 `@名字`、迭代 `迭代:名称`。**指代不明时不许猜**：返回候选清单（编号 + 名称 + 区分信息）让人选，错误句子写明"有 3 个叫「登录」的任务，告诉我编号"。
6. **同一件事只有一条路径**：不提供语义重复的工具；工具描述写明前置顺序（"开始任何任务前先 get_task_brief"）。
7. **安装零门槛**：以上能力对用户不增加任何步骤。斜杠命令随 MCP 连接自动出现；接入仍然只是把 `/connect` 那段话贴给 Agent。接入说明里增加一步"告诉用户现在可以用哪些斜杠命令"。

## 被否决的

- **让 Agent 自己维护一份命令清单**：清单会过期，且每个客户端要各写一份。由服务器提供，升级只改一处。
- **要求用户安装 CLI 或插件**：与 ADR 0024 的取向相反，门槛应该为零。
- **靠更长的系统提示词约束 Agent**：提示词只能提高概率，挡不住歧义；结构化参数才是确定的。

## 后果

- MCP 服务端新增 prompts 能力与八条提示；工具签名新增两个可选参数；新增一个只读工具。
- 幂等键需要一张小表（键、组织、执行者、工具名、参数指纹、状态、占位时刻、结果引用、结果、过期时间）。
- 接入说明与文档同步；`docs/agent-integration.md` 增加"斜杠命令"一节。
