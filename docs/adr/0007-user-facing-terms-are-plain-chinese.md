# 面向用户的名称一律用日常中文，英文只做代码标识符

这套系统的目标是让组织里每个人（不只是研发）都能通过它和 Agent 协作，上手门槛必须低。早期设计稿用 Run、Backlog、Grant、Proposal 这类词作为概念的正式名称，用户看不懂。我们决定：`CONTEXT.md` 里每个概念的正式名称是一线员工不需要解释就懂的中文（执行记录、待领取任务、授权、待确认操作），界面、通知、报表、给 Agent 的说明里只出现这些中文；英文名只作为代码里的类型名与字段名，写在括号里备查。

## Consequences

- 命名新概念前先问："销售或 HR 看到这个词知道是什么吗？"不知道就换成他们会用的词。
- 内部实现可以用英文标识符，但一旦出现在任何人会读到的地方（含 Agent 的 MCP 工具描述与错误信息），必须换成词汇表里的中文。
- 精确性让位于可懂性：宁可用"执行记录"这种略长的词，也不发明缩写。
