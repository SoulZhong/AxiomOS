# 界面设计规范改以 Linear 为蓝本，并叠加克制的"Axiom 母舰"科幻层

产品名 AxiomOS 取自《机器人总动员》里的星舰 Axiom，用户希望整套系统带有科技与科幻气质，包括登录页。ADR 0009 采用的 Sentry 蓝本是浅色工作画布加品牌面的两世界结构，与这一诉求不合。我们决定改以 Linear 的设计语言为蓝本（`docs/design/sources/linear-DESIGN.md`）：近黑画布、四级表面阶梯、细线分层、唯一的薰衣草蓝强调色、无阴影、负字距标题、Inter 与 JetBrains Mono 作为其自有字体的公开替代；在此之上只允许八处明确列出的科幻元素（星图、轨道舰徽、等宽眉标、状态指示灯、遥测读数、面板接缝高光、网格地平线、入场动效），其余一律禁止。规范见 `web/DESIGN.md` v2。

## Considered Options

- **保留 Sentry 蓝本，只把登录页做成科幻风**：两种气质割裂，工作页面仍是浅色办公软件。
- **完全自创赛博朋克风格**：霓虹、渐变、扫描线容易廉价，且与"密集可扫读"的工作台需求冲突。
- **Linear 蓝本 + 克制的科幻层（选定）**：Linear 本身就是深色、精确、单一强调色的"软件工艺"气质，天然接近舰桥控制台；科幻感靠材质和仪表而不是特效，能与密集数据共存。

## Consequences

- 深色为默认，另有同一套 token 的浅色模式（用户当日追加）；品牌页始终深色。
- 组件细则（芯片条、头像、ID 位置、动作条分组、动态合并、目标树、抽屉分组等）从 v1 原样继承，仅换色。
- 科幻元素以规范里的八处为白名单；新增装饰必须先写进规范。
