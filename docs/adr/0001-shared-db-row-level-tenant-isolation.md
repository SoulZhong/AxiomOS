# 多租户采用共享数据库 + 组织 ID 行级隔离

AxiomOS 需要同时以在线多租户和私有化单租户两种形态交付，初期单个组织规模约 1000 人。我们决定两种形态使用同一套代码和同一种数据模型：所有组织共享一个数据库，每行数据携带组织 ID（`org_id`），并在数据库层（RLS）强制隔离；私有化部署就是只有一个组织的同一系统。

## Considered Options

- **每个组织独立数据库或 Schema**：隔离最强，但运维成本随组织数线性增长，且在线与私有化会分化成两条代码路径。
- **共享库 + 应用层过滤**：实现最简单，但任何一处漏加组织过滤就是跨组织泄露。
- **共享库 + 数据库层强制隔离（选定）**：隔离由数据库保证，应用层漏写过滤也不会泄露；两种部署形态零分叉。

## Consequences

- 所有表必须带组织 ID，所有数据库连接必须先设置当前组织；这是不可绕过的约定。
- 未来若某个组织体量远超其他组织需要单独迁库，应新增 ADR，而不是在应用层做特例。
