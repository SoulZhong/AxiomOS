# ADR 0021：路线图是目标的一种看法，不是新对象

日期：2026-09-07 · 状态：部分被取代（第 3、4 条见 ADR 0022） · 关联：ADR 0012（看板是视图）、0016（里程碑）、0014（可定制边界）

## 背景

调研后确认（`docs/design/sources/` 与本次讨论）：路线图与甘特图回答的是两类问题。路线图回答"接下来要解决什么问题、为什么是它、大概什么时候"，单位是成果，刻度是季度或"现在 / 下一步 / 以后"，读者包括不在系统里干活的人；甘特图回答"谁在什么时候做哪件事、谁卡谁"，单位是工作包，刻度是天。把甘特图当路线图发出去，日期就变成了承诺，学到新东西反而成了"延期"。

我们已有目标树（负责人、进度汇总、里程碑、目标甘特图）与任务甘特图（依赖、迭代）。缺的不是一个新对象，而是路线图这一层表达**意图**的东西。

## 决策

1. **不新增"路线图"对象**。路线图是「目标」页下的一个页签，与树、甘特图并列，是同一批目标的不同看法（ADR 0012 的原则）。
2. **目标新增三个字段**，都可空：
   - `horizon`：粗时间桶，取值 `now | next | later`，默认空（未排期）。它与计划起止**互不覆盖**：有精确日期时时间桶只作分组，没有日期时时间桶就是唯一的时间表达。
   - `confidence`：信心度，取值 `high | medium | low`，默认空。路线图上显式呈现，任务与甘特图**永远不继承**它。
   - `outcome`：一句话成果指标（如「登录转化率从 62% 提到 70%」），纯文本，可空。
3. **路线图页签的形态**：按 `horizon` 分三列（现在 / 下一步 / 以后），每列内按泳道分组，泳道默认是团队（可切换为负责人）。卡片显示目标标题、成果指标、负责人、进度、最近里程碑、信心度标记；点开进目标详情。未排期的目标进"还没排期"一栏。有精确日期的目标在卡片上显示日期，但**页签本身不画时间条**——要看时间条就去甘特图页签。
4. **默认页签是路线图**。进入「目标」先看到方向，需要细节再切树或甘特图。`?view=` 记住上次选择，旧链接（`?view=tree`、`?view=gantt`）照旧可用。
5. **对外只读分享**（规划中的功能）只允许分享路线图与目标甘特图，且不含成本；任务甘特图不对外分享，避免把精确排期变成对外承诺。
6. **写死的部分**：时间桶只有三档、信心度只有三档，不做成可配置词表——多一档就会有人拿它当"第四季度"，路线图立刻退化成排期表（ADR 0014 的边界：管理策略可配，表达方式写死）。泳道口径（团队 / 负责人）可切换，属于看法不属于策略。

## 后果

- 迁移新增三列，旧目标全部为空，页面显示为"还没排期"，不影响任何既有行为。
- 目标的就地编辑增加这三项；批量把目标拖进某一时间桶是路线图页签的主要交互。
- 词汇表新增「路线图」「时间桶」「信心度」「成果指标」，并注明避免用 Roadmap、Q1/Q2、把握度。
